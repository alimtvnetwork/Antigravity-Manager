## 1. Executive Summary & Architectural Rationale

This component specification defines the architectural refactoring for conditional expressions, compound predicate chains, mixed polarity evaluations, and inline boolean closures across three critical backend Rust subsystems:
1. **`transcript.rs`**: JSONL conversation log inspection, turn-level completion detection, subagent classification, and prompt turn extraction.
2. **`send_flow.rs`**: Interactive Telegram `/send` flow state transitions, debounce tapping guards, machine and instance pickers, and prompt consumption.
3. **`acquire.rs`**: Supabase distributed workspace lease acquisition and lease conflict validation.

### Core Problems Remediated
- **Compound Multi-Clause Conditions:** Multiple expressions chain 4 to 8 clauses with mixed `&&` and `||` operators inline, exceeding the 2-operand limit without affirmative sub-expression decomposition (violating Principle 4).
- **Mixed Polarity Checks:** Inline checks conflating affirmative positive matches with negated exclusion checks (e.g. `is_user_input && !is_system_msg` or `current_expires > now && !current_owner.eq_ignore_ascii_case(node_id)`), introducing mental burden and edge-case fragility (violating Principle 6).
- **Double Negatives & Negative Identifiers:** Methods and expressions framed negatively (e.g. `!picker_safe`, `!is_internal`, or `!is_system_msg`), contrary to affirmative naming principles (`is*`, `has*`).
- **Code Duplication Across Parse Loops:** Identical 6-clause telemetry checks, 5-clause tool step checks, and 8-clause system message prefix filters were duplicated verbatim across multiple scan passes in `transcript.rs`.

## 2. Target File 1: `src-tauri/src/modules/repo_db/transcript.rs`

### 2.1 Subsystem Context & Role
`transcript.rs` processes conversation transcripts (`transcript.jsonl` and `transcript_full.jsonl`) generated by Antigravity IDE instances. It performs fast bounded reverse scans to differentiate step-level tool executions (`DONE`) from turn-level model terminal completions, extracts prompt turns, identifies subagent-spawned conversations, and parses attached images.

### 2.2 Affirmative Predicate Helper Specifications

```rust
/// Evaluates whether text content contains known subagent role or instruction markers.
pub(crate) fn is_subagent_prompt_text(txt: &str) -> bool {
    let is_caller_invoked = txt.contains("You are ");
    if is_caller_invoked {
        return true;
    }
    let txt_lower = txt.to_ascii_lowercase();
    let has_role_identity = txt_lower.contains("subagent")
        || txt_lower.contains("worker")
        || txt_lower.contains("author")
        || txt_lower.contains("research")
        || txt_lower.contains("debugger");
    let has_execution_signature = txt_lower.contains("invoked by a caller agent")
        || txt_lower.contains("execute enhanced read memory");
    has_role_identity || has_execution_signature
}
```

#### 7. `is_system_prompt_message`
```rust
/// Determines whether message content represents internal system prompts or subagent instructions.
pub(crate) fn is_system_prompt_message(s_source: &str, content: &str) -> bool {
    if s_source.eq_ignore_ascii_case("SYSTEM") {
        return true;
    }
    let trimmed = content.trim();
    let lower = trimmed.to_ascii_lowercase();
    let has_system_tag = lower.starts_with("<system_message>")
        || lower.starts_with("the following is a <system_message>");
    let has_envelope_header = lower.starts_with("[message] timestamp=")
        || trimmed.starts_with("Task id ");
    has_system_tag || has_envelope_header
}
```

#### 8. `is_content_truncated`
```rust
/// Evaluates whether a transcript step records content truncation requiring full transcript lookup.
pub(crate) fn is_content_truncated(val: &serde_json::Value) -> bool {
    val.get("truncated_fields")
        .and_then(|tf| tf.as_array())
        .map(|arr| arr.iter().any(|v| v.as_str() == Some("content")))
        .unwrap_or(false)
}
```

```rust
/// Pre-filters raw transcript lines for candidate user or planner markers prior to JSON parsing.

        || trimmed.contains("\"MODEL\"")
        || trimmed.contains("\"model\"");

}
```

## 3. Target File 2: `src-tauri/src/modules/telegram_inbound/send_flow.rs`

### 3.1 Subsystem Context & Role
`send_flow.rs` orchestrates the multi-step interactive Telegram `/send` flow: picking target host machine -> picking IDE instance profile -> picking project/conversation -> dispatching prompt injection.

### 3.2 Affirmative Predicate Helper Specifications

#### 1. `is_valid_send_token`
```rust
/// Callback payloads use `|` as separator; entries containing it (or `:`)
/// corrupt parsing, so they are excluded from pickers.
fn is_valid_send_token(token: &str) -> bool {
    let clean = token.trim();
    if clean.is_empty() {
        return false;
    }
    let has_separator = clean.contains('|') || clean.contains(':');
    !has_separator
}
```

#### 2. `is_machine_entry_usable`
```rust
/// A machine label is picker-usable when it round-trips through a
/// `send:m:<label>` callback payload: no separator characters and inside
/// Telegram's 64-byte `callback_data` cap.
fn is_machine_entry_usable(label: &str) -> bool {
    let is_safe = is_valid_send_token(label);
    let payload = format!("send:m:{label}");
    let has_fitting_payload = callback_fits(&payload);
    is_safe && has_fitting_payload
}
```

#### 5. `is_duplicate_send_machine_tap`
```rust
/// Debounce guard: determines if chat already has a fresh Step 2 flow for this machine (<3s).
fn is_duplicate_send_machine_tap(
    existing_machine: &str,
    candidate_alias: &str,
    stage: SendStage,
    elapsed_secs: u64,
) -> bool {
    let is_pick_instance = stage == SendStage::PickInstance;
    let is_same_machine = is_matching_target_machine(existing_machine, candidate_alias);
    let is_within_debounce = elapsed_secs < 3;
    is_pick_instance && is_same_machine && is_within_debounce
}
```

#### 6. `is_matching_machine_alias`
```rust
/// Resolves whether an entry alias matches user-specified alias or local aliases.
fn is_matching_machine_alias(entry_alias: &str, input_alias: &str) -> bool {
    if entry_alias.eq_ignore_ascii_case(input_alias) {
        return true;
    }
    let is_local_keyword = input_alias.eq_ignore_ascii_case("local")
        || input_alias.eq_ignore_ascii_case("localhost");
    let is_entry_current = super::node_label::is_current_machine(entry_alias);
    is_local_keyword && is_entry_current
}
```

#### 7. `is_instance_mismatch`
```rust
/// Determines if an active prompt's instance conflicts with the target instance filter.
fn is_instance_mismatch(prompt_instance_id: &str, target_instance_id: &str) -> bool {
    let has_prompt_instance = !prompt_instance_id.trim().is_empty();
    let has_target_instance = !target_instance_id.trim().is_empty();
    let is_both_specified = has_prompt_instance && has_target_instance;
    let is_different = !prompt_instance_id.eq_ignore_ascii_case(target_instance_id);
    is_both_specified && is_different
}
```

```rust
/// Determines if an existing lease record is unexpired and owned by a foreign node.
pub(crate) fn is_lease_held_by_other_node(
    expires: i64,
    now: i64,
    owner: &str,
    node_id: &str,
) -> bool {
    let is_unexpired = expires > now;
    if !is_unexpired {
        return false;
    }
    let is_same_node = owner.trim().eq_ignore_ascii_case(node_id.trim());
    !is_same_node
}
```
