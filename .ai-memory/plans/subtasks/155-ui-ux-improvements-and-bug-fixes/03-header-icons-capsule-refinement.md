## Objective
Refine the navigation capsule in the header into a unified, elegant segmented pill following AGENTS.md design guidelines.

## Target Files
- `src/components/navbar/NavMenu.tsx`
- `src/components/navbar/Navbar.tsx`

## Technical Details
