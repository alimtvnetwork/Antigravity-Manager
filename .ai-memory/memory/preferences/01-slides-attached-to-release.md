# Command: Attach slides deck to release section

Verbatim: "attach the slides system to the release section as well".

Scope: every release must publish the built slides deck (`slides-app/dist.zip`) as a release asset, and the root README release section must link to it.

When it applies: `npm run release` / `scripts/release.mjs` and the release ceremony memory (`mem://preferences/release-ceremony`).
