# Rule: Prompt Tree UX, Origin Hierarchy & FIFO Restoration Invariants

1. **Toolbar Capsule & Inline Select Discipline:** When rendering adjacent toolbar actions or desktop window controls, wrap them into contiguous segmented pill capsules (`rounded-full`, shared border, subtle divider lines, dark-glass styling). Inline `<select>` dropdowns mounted inside segmented capsules MUST use transparent borderless styling (`bg-transparent border-0 focus:ring-0 focus:outline-none`) to prevent nested pill-in-pill visual defects.
2. **4-Tier Prompt Origin Hierarchy:** Prompt tree views and inspectors must discriminate among 4 distinct origin tiers: `USER_PROMPT` (Sky badge, User icon), `SUBAGENT_INSTRUCTION` (Purple badge, Bot icon), `SYSTEM_MESSAGE` (Zinc badge, Terminal icon), and `TOOL_OUTPUT` (Amber badge, Wrench icon). Subagents must nest hierarchically beneath their parent user prompt with branch glyphs (`↳`, `└──`).
3. **Interactive Truncation Callouts:** Never render raw `<truncated N bytes>` or `<truncated N lines>` markers as plain text; parse and render them as interactive dark-glass omission banners (`⚡ [Omitted N bytes/lines of context - Click to inspect/expand]`).
4. **FIFO Restore & Queue Invariant:** All prompt restore, dispatch, and queue processing queries across SQLite databases (`active_prompts`, `prompt_backups`, `repo_prompts.db`) MUST enforce strict First-In-First-Out ordering using `ORDER BY created_at ASC, id ASC`. Inverted LIFO queries (`ORDER BY updated_at DESC`) are strictly forbidden in dispatch logic.
5. **Deep Transcript Inspection & Full Log Precedence:** When inspecting conversation transcripts, always prioritize un-truncated `transcript_full.jsonl` over `transcript.jsonl`. Reverse-scan across at least 10 lines, bypassing trailing `TOKEN_USAGE`, `HEARTBEAT`, and `TELEMETRY` records, to extract genuine tool executions (`tool_calls`) and assistant thoughts (`thinking`).
