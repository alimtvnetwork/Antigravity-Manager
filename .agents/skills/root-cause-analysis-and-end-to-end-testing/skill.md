# Root Cause Analysis and End-to-End Testing Skill

## Overview
This skill provides operational procedures, architectural specifications, and verification suites for:
1. Resolving prompt tree discrepancies between IDE active conversations, queued messages, and AGM tree representations.
2. Restoring image loading and preview rendering by granting Tauri `core:asset:default` permissions and unblocking legitimate Windows user profiles (`C:\Users\Administrator`) in filesystem security guards.
3. Eliminating redundant UI button artifacts (e.g. duplicate `Expand full text` triggers).
4. Ensuring cross-machine Telegram and GitMap SSH connectivity between fleet cluster nodes.
