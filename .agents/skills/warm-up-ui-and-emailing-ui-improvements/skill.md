# Warm Up UI and Emailing UI Improvements Specification & Architecture

## Overview
This skill guides the discovery, architectural design, component modeling, and verification specification for 100 discrete improvements spanning:
1. **Smart Warmup Dashboard & Telemetry Visualizers**: Live token expenditure, quota countdown clocks, wave animations, and real-time execution feeds.
2. **Batch Warmup Orchestration & Account Matrix Controls**: Staggered schedule jitter, multi-account warmup matrix, and quota reserve guards.
3. **Warmup CLI Ergonomics via GitMap**: High-speed termtable rendering, interactive terminal dashboards, and headless automation.
4. **Unified Email Command Center & Health Diagnostics**: Diagnostic ladder (DNS MX -> TLS -> Auth -> IMAP Ping), status badge capsules, and connection probes.
5. **Visual Email Template Designer & Dual-Theme Previews**: Real-time HTML rendering, Outlook/Gmail dark-mode toggle simulator, and token previewers.
6. **Inbound Remote Command Playground & Security Shields**: Email command simulators, SPF/DKIM validation badges, and execution sandbox controls.
7. **Email CLI Management via GitMap**: Headless email configuration, test email dispatches, and watcher daemon management.

- **Strictly Relative Git Paths**: All paths referenced must be repository-relative (`02-spec/...`, `.ai-memory/...`, `src/...`).
- **Zero Builds / Zero Tests Rule**: During specification planning, strictly refrain from executing `cargo build`, `npm run build`, `npm test`, or test runners.
- **Design System Invariants**: Adhere to `02-spec/02-coding-guidelines/` and `02-spec/07-design-system/` — segmented pill capsules (`rounded-full`), transparent dropdowns, 4-tier origin badges, and dark-glass aesthetics.
